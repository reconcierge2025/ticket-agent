# סוכן הכרטיסים 🎟️

סוכן שסורק את **קופת תל אביב** (וגם comy / grayclub) ואת **Ticketmaster ישראל**, מוצא את המקומות הכי קרובים לבמה בכל אזור, ושולח לך הודעה בטלגרם.

## מה הוא עושה
- **שולח לו קישור למופע:** הוא בודק **את כל התאריכים** ושולח את **הכי טוב שמצא**, בכל אזור ולכל כמות של **2–5 כרטיסים צמודים**. 🎯 מסמן שורות 1–4. הדוח מגיע רק למי שביקש, עם כפתורים.
- **אחר כך** תקבל הודעה רק כשנמצא משהו **קרוב יותר** ("⬆️ ... היה שורה 7").
- **🔥 מעקב צפוף** למופע חם: בדיקה כל 3 דקות, וההתראות מגיעות גם בלילה.
- **סריקה כללית** של כל המופעים באתרים, עם **הודעת סיכום אחת**.
- **מצב קנייה (במחשב):** מחכה בתור ומעדכן אותך ככל שהוא מתקדם.
  - **Ticketmaster:** בוחר לבד את הגוש הכי טוב ואת הכמות, **ומגיע עד עמוד התשלום**.
  - **קופת ת"א:** פותח את המופע בחלון שבו אתה מחובר ושולח לך בדיוק על אילו מושבים ללחוץ.
  - **אפשר לתזמן מראש:** `/sale <קישור> 2 10:00`, והסוכן ייכנס 10 דקות לפני פתיחת המכירה.
- **מקצועי:** סיכום "☀️ בוקר טוב, הסוכן פועל" כל בוקר, התראה ⚠️ אם אתר שינה מבנה או חוסם, בדיקת לילה אוטומטית מול האתרים, שעות שקט (23:00–08:00, הודעות לא דחופות נאספות לבוקר), ורשימת מעקב נפרדת לכל משתמש.

> 🔒 הסוכן לא מזין פרטי אשראי, לא עוקף תורים ולא פותר "אני לא רובוט". את התשלום אתה עושה.

## 🌍 הופעות בחו"ל (ממשקים רשמיים)
האתרים הגדולים בחו"ל (Ticketmaster, Live Nation, SeatGeek) חוסמים גלישה אוטומטית, והסוכן לא עוקף את החסימה. במקום זה הוא משתמש **בממשקים הרשמיים** שהם מציעים למפתחים, בחינם:
- **Ticketmaster Discovery API:** Ticketmaster בארה"ב, בבריטניה, באירופה, בקנדה ובאוסטרליה, וגם Live Nation. מחזיר תאריכים, ערים, אולמות, **מתי נפתחת המכירה ופריסיילים**, טווח מחירים ומצב.
- **SeatGeek API:** **המחיר הכי זול כרגע** וכמה כרטיסים יש בשוק.

**מה מקבלים:**
- `/abroad Coldplay`: כל ההופעות בחו"ל.
- `עקוב אחרי ...`: גם הופעות בחו"ל. כל 4 שעות נבדקים האמנים שאתה עוקב אחריהם ו-55 האמנים הבינלאומיים מהרשימה, ונשלחות התראות על:
  - 🌍 הופעה חדשה
  - ⏰ המכירה נפתחת בתוך 24 שעות (בשעון ישראל)
  - 🔑 פריסייל בקרוב
  - ⬇️ ירידת מחיר של 10% ומעלה
  - ⚠️ דחייה או ביטול
- מפת מושבים ושורה מדויקת הממשקים האלה לא נותנים. ל-StubHub ול-AXS אין ממשק פתוח.

**איך משיגים את המפתחות (חינם, 5 דקות):**
1. **Ticketmaster:** נרשמים ב-**developer.ticketmaster.com** ← My Apps ← מעתיקים את ה-**Consumer Key**.
2. **SeatGeek:** נכנסים ל-**seatgeek.com/account/develop** ← יוצרים אפליקציה ← מעתיקים את ה-**Client ID**.
3. מכניסים את המפתחות:
   - **Railway:** Variables ← `TICKETMASTER_API_KEY` ו-`SEATGEEK_CLIENT_ID`
   - **GitHub:** Secrets באותם שמות
   - **במחשב:** ב-`config.json` תחת `"apis"`

אפשר להתחיל רק עם Ticketmaster. **הגדרות:** `intl.countries` מגביל למדינות מסוימות, למשל `["GB","DE","FR","NL","US"]`. `intl.everyHours` קובע כל כמה שעות לבדוק. `intl.israeliStars: true` בודק גם את האמנים הישראלים בחו"ל.

## 🧠 לומד ומשתפר לבד
- **🆕 מופעים חדשים:** בכל סבב הסוכן משווה למה שכבר ראה ושולח "עלו X מופעים חדשים", עם כפתור **👀 עקוב** ליד כל מופע. בפעם הראשונה הוא רק לומד מה קיים, בלי הודעות.
- **🌟 100 אמנים מובילים (`/stars`):** הסוכן עוקב אוטומטית אחרי כ-50 אמנים ישראלים (עומר אדם, אודיה, נועה קירל...) וכ-55 בינלאומיים (ביונסה, אדל, אד שירן, טום אודל, קולדפליי...). כשיש הופעה של אחד מהם באחד האתרים, קיימת או חדשה, מגיעה הודעה עם כפתור 👀, פעם אחת לכל מופע. את הרשימה אפשר לערוך ב-`src/artists.js`, או לכבות עם `"stars": false` ב-config.
- **🔤 עברית ↔ אנגלית:** אמן נמצא גם כשהשם כתוב בשפה אחרת, לפי הצליל (Shlomo Artzi = שלמה ארצי).
- **⭐ מעקב אחרי אמן:** `/follow שלמה ארצי` שולח לך הודעה אישית מיד כשעולה לו מופע חדש באחד האתרים. `/follows` מציג את הרשימה, `/unfollow שם` מסיר.
- **🧠 אתרים חדשים ששולחים לו:** קישור מאתר שלא ברשימה מקבל ניסיון זיהוי אוטומטי. אם יש מפת vivenu, הסוכן מביא מושבים. אחרת הוא עוקב אחרי זמינות ומחיר. כשזה עובד הוא זוכר את האתר ושולח "למדתי לעבוד עם אתר חדש".
- **🔎 מוצא אתרים לבד:** בזמן הסריקה הסוכן אוסף קישורים לאתרי כרטיסים אחרים, בעיקר דרך טיקצ'אק LIVE, ובודק עד 3 חדשים בכל סבב. מה שנמצא מגיע אליך בהודעה ומופיע ב-`/sites` תחת "מצאתי לבד".
- **🔧 תיקון עצמי:** אם השיטה הרגילה של אתר נכשלת פעמיים, הסוכן עובר לבד לשיטה חלופית (זמינות ומחיר), כדי שלא תישאר בלי מידע. במקביל מגיעה התראת ⚠️ אם אתר שינה מבנה.

## 🤖 תפיסה אוטומטית ואיפה ההזמנה מופיעה
- **רק במופעים שתבחר:** בדוח של מופע לוחצים **🤖 תפוס לי אוטומטית**. כשיימצאו מקומות בשורות 1–4, הסוכן יתפוס אותם בלי לשאול.
- **ההזמנה נפתחת בחלון Edge במחשב,** בחלון נפרד של הסוכן שבו התחברת עם `npm run login`. שם משלמים.
- **לטלגרם מגיע צילום מסך** של החלון, עם כפתור **❌ בטל וסגור את החלון**.
- **לא רוצה?** לוחצים ❌ או פשוט לא משלמים. אף אתר לא גובה כסף בלי תשלום, והמושבים משתחררים לבד אחרי כמה דקות.
- **לא ליד המחשב?** אפשר להיכנס למחשב מהטלפון עם **Chrome Remote Desktop**, ולשלם בחלון שהסוכן פתח.
- **עובד רק במחשב** (`npm start`), כי צריך חלון שבו אתה מחובר. השרת וגיטהאב רק מתריעים.

## א. בוט טלגרם (פעם אחת)
1. ב-**@BotFather**: `/newbot` ← שם ← שם משתמש שנגמר ב-`bot` ← מעתיקים את ה-**token**.
2. פותחים את הבוט ולוחצים **Start**. הבוט יחזיר את **מספר הצ'אט** שלך.
3. **עוד אנשים:** כל אחד שולח לבוט הודעה, מקבל את המספר שלו ושולח לך. אתה מוסיף את המספרים לרשימה (מופרדים בפסיק).
4. 🔐 אם הטוקן נחשף אי פעם (נשלח בצ'אט, נשמר בקובץ משותף): ב-BotFather שולחים `/revoke`, ואת הטוקן החדש מעדכנים בכל מקום.

## ב. שרת Railway – 24/7 (כ-5$ לחודש)
1. נרשמים ב-**railway.com** עם חשבון ה-GitHub ובוחרים במסלול **Hobby** (5$ לחודש).
2. **New Project ← Deploy from GitHub repo ← `ticket-agent`**. Railway יזהה את ה-`Dockerfile` לבד.
3. בשירות שנוצר:
   - **Variables:** מוסיפים `TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_IDS` (למשל `444349705`).
   - **Volume:** לוחצים קליק ימני על השירות ← **Attach Volume** ← Mount path: `/data`. כאן נשמרים המעקבים, כדי שלא יימחקו בעדכון.
4. **Deploy.** תוך כמה דקות תקבל בטלגרם "🟢 סוכן הכרטיסים פועל (שרת)".
5. **מכבים את GitHub**, כדי שלא יענו שניים: בריפו **Settings ← Secrets and variables ← Actions ← Variables ← New variable**: `USE_SERVER` = `true`.

כל `git push` לריפו מעדכן את השרת אוטומטית.

1. בריפו: **Settings ← Secrets and variables ← Actions ← Secrets**: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_IDS`.

## ד. במחשב (כולל מצב קנייה)
```
npm install
copy config.example.json config.json
```
ממלאים ב-`config.json` את `botToken` ואת `chatIds`. הקובץ **לא עולה לגיטהאב**.

**התחברות לאתרים, פעם אחת:**
```
npm run login -- "https://www.ticketmaster.co.il" "https://tickets.kupat.co.il"
```
מתחברים בחלון שנפתח וסוגרים אותו. ההתחברות נשמרת ב-`data/profile`. אם גוגל חוסם, התחבר עם האימייל והסיסמה של האתר.

**הפעלה:** `npm start`. להפעלה אוטומטית עם Windows: `powershell -ExecutionPolicy Bypass -File .\install-autostart.ps1`
